# Pilo System

A handcrafted expansion to the Dres system for Kerbal Space Program.

Created by Wistful.

## Overview

The Pilo System transforms Dres into a larger outer-system destination featuring:

- Pilo, an ore-rich atmospheric moon
- Celia, a volcanic submoon that lights Pilo's skies
- Custom terrain generation
- Atmospheric gameplay progression
- Experimental visuals and lighting

This project is currently in very early development and is considered pre-alpha.

## Features

- Expanded Dres system
- Thin breathable atmosphere on Pilo
- Volcanic "lava star" Celia
- Procedural terrain generation
- Polar submoon orbit
- Experimental EVE visuals

## Requirements

Required:
- Kopernicus
- ModuleManager
- EVE Redux

Recommended:
- Scatterer

## Installation

1. Install dependencies
2. Drag the included `GameData` folder into your KSP install
3. Launch KSP 1.12.5

## Known Issues

- Terrain and visuals are still placeholder
- Balance is unfinished
- Some lighting effects are experimental
- Existing saves are NOT recommended
